# Arbiter

A rule-based decision engine that evaluates applications against
predefined policies, with optional written justifications and
AI-assisted analysis.

## Overview

Arbiter provides a structured workflow for submitting applications,
answering questions, and evaluating decisions against configurable
rules.

The project starts with a simple question-and-answer workflow and
can evolve to support more sophisticated evaluation mechanisms.

## Planned Features

- [ ] MCQ-based applications
- [ ] Rule-based decision evaluation
- [ ] Written justifications
- [ ] Configurable application types
- [ ] Decision history and persistence
- [ ] AI-assisted analysis

## Design Principles

- Deterministic rule evaluation
- Separation of application data and evaluation logic
- Minimal dependencies
- Incremental development
- Optional AI integration

## Tech Stack

- Python
- SQLite (planned)
- LLM API integration (optional, planned)
